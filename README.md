# Librairie-Agro

## Bibliothèque Agro-business 

# Application web pour gérer une bibliothèque de livres spécialisés agro-business.  

# Fonctionnalités

- *Ajouter / Supprimer / Modifier* des livres : titre, auteur, année, catégorie, statut lu/non lu
- *Stockage local* : tes données restent dans le navigateur via `localStorage`
- *Mise en page responsive* avec *CSS Grid* : sidebar filtres + grille de livres auto-adaptative
- *Marquer comme lu* en 1 clic
- *Pré-remplissage* avec 15 livres agro-business au 1er lancement, dont plusieurs sur les vergers

# Catégories gérées

- Production végétale / Maraîchage
- *Arboriculture / Vergers*
- Elevage
- Agro-transformation
- Gestion & Economie agricole
- Financement
